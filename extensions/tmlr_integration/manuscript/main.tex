\begin{abstract}
Kernel Affine Hull Machines (KAHMs) reconstruct observations from local
reference sets. We study whether these reconstructions provide useful
features for a finite-dimensional forecasting decoder. We interpret
normalized target transfer as a ratio of kernel-ridge predictions,
connecting the established KAHM construction to rescaled kernel
interpolation. We give sufficient conditions under which KAHM and matched
radial-basis-function (RBF) reconstructions generate the same augmented
feature span, and construct an irregular reference set for which the spans
differ. Separately, bounded features and a ridge residual decoder yield a
uniform bound on the forecast correction, including its free intercept.
A prospectively specified experiment compares ten procedures on 192 task
suites: three nonlinear simulation laws and a linear control, two
observation-noise levels, and 24 independent repetitions. Local dimension
is selected before correction calibration, independently for each geometric
procedure. Bounded KAHM departure reduces aggregate nonlinear normalized
mean squared error by \DFGainCommon\% relative to common local-coordinate
features and \DFGainRawRBF\% relative to raw-input RBF forecasting;
both establish a prespecified 3\% margin under simultaneous inference.
Its gains over independently selected RBF departures and boosted trees
are \DFGainRBF\% and \DFGainHGB\%, below that margin. A selected non-KAHM
procedure attains lower error. Dimension selection improves KAHM by
\DFDimensionGain\% relative to a fixed cap of two, while a default cap
of twenty increases error in these twelve-dimensional histories.
Matched-bank controls attribute the dimension improvement to stronger
common features despite a smaller incremental departure benefit.
Correction bounds and linear-control noninferiority hold, but the joint
performance criterion is not established. Supporting studies delimit
transfer to natural series and adaptive procedures. The evidence supports
conditional forecasting value without establishing a general advantage
specific to KAHM.
\end{abstract}
