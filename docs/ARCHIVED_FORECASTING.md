# Archived forecasting experiment

## Evaluation objective and data allocation

Protocol `KAHM-SCORE-20261102-v1` compares complete forecasting procedures, each comprising reconstruction, encoding, decoder and validation selection. It is distinct from the executable fixed-geometry and target-changing experiments. The four observation laws are linear autoregression, nonlinear autoregression, Van der Pol and Duffing, with the equations, initial distributions, innovations, sensor noise, integration steps and observation spacing in [Experimental protocols](PROTOCOLS.md#1-fixed-geometry-forecasting). The archived oscillator episodes draw position, velocity, phase and then 72 sensor-noise values in that order; phase is drawn for both laws and used only for Duffing. Each episode contains 72 retained values after the stated burn-in.

Each law has 64 independent repetitions, giving 256 law–repetition tasks. The four independently generated episode sets serve the following roles.

| Set | Role | Episodes | Retained windows |
| --- | --- | ---: | ---: |
| A | Preprocessing, reference construction and fitting | 64 | 512 |
| B | Selection of candidate settings | 32 | 256 |
| C | Diagnostic assessment only | 32 | 256 |
| D | Final assessment | 128 | 1,664 |

Histories have width 12; targets are the values at horizons 1, 4 and 12. Zero-based origins 11, 15, ..., 59 give 13 windows per episode. A, B and C sample the indicated numbers of pooled windows uniformly without replacement and sort the retained rows by episode and origin. D retains every window. All procedures share the retained observations; overlapping windows are not independent repetition units.

The recorded seed namespace is `kahm-score-enrichment-final|2026-11-02|v1`, and the recipe is `SHA256(namespace|law|rep|split|purpose)`. Data and row-sampling seeds use the first 16 digest bytes as a big-endian integer; fitting seeds use the first four bytes. The specified generator is NumPy PCG64 (`default_rng`). The exact task roster, stream assignments, original generator and fitting source are unavailable. This specification is not a claim of exact regeneration.

## Numerical representation conventions

The input is standardized using retained A histories, with population variance divisor 512 and scales at most $10^{-12}$ replaced by one. Two independently fitted k-means partitions request 2 and 4 groups, with five initializations and at most 150 iterations. If distinct rows are insufficient the request is reduced; unresolved empty groups trigger recorded attempts with halved counts. At most 24 reference histories are sampled without replacement per group. Reference identities remain fixed across caps $1,2,4,8,12$. Reference arrays are stored at float32 precision and converted to float64 for fitting. The initial local rank request is $\min(c,d,n_j-1)$, using covariance divisor $n_j-1$ and eigenvalues greater than float64 machine epsilon. The projected coordinate ranges are required to be at least $10^{-3}$; otherwise the request is reduced to one as necessary, with remaining violations recorded. Constant or singleton groups use rank zero, return their mean, and supply no local coordinates. Unexpected factorization failures stop the computation.

Reconstruction and score equations are defined in the [Scientific reference](SCIENTIFIC_REFERENCE.md). The reference-only regularizer uses $\nu=\|Q\|_F^2/(nd)$, begins at $2.5\nu$, computes $C=(G+\lambda I)^{-1}$ and proposes $2\nu+\|Q-GCQ\|_F^2/(nd)$. Stop at a change of at most $10^{-3}$ or 100 inverse computations; retain the last computed pair. Positive-rank fits require finite positive regularization. Kernel evaluation rescales by the maximum log similarity for each query; failed finite-value or signed normalization checks use affine reconstruction and recompute the complete score. The cancellation threshold is $10^{-10}$. A negative signed sum alone does not trigger fallback. Full-rank affine reconstruction returns the input directly. The zero-vector angular convention gives $T(0,0)=1/(2\sqrt 2)$. Scores are clipped to $[0,1]$ for rounding. Log-sum-exp forms memberships with $\tau=10^{-6},\ \omega=16$, without a uniform-membership fallback.

## Decoder construction and selection

Each reconstruction supplies Mem, Norm, Local and Score as defined in the [Scientific reference](SCIENTIFIC_REFERENCE.md). The raw control receives the standardized history. Every encoding column is centered and scaled using A means and population standard deviations; scales below $10^{-8}$ are replaced by one. Shared membership columns use identical transformations at the same reconstruction and cap.

The linear decoder uses the standardized encoding $u$ directly. The nonlinear decoder appends a standardized Gaussian Nyström block with 64 common A row identities as landmarks. The landmark coordinates depend on the encoding. Let $\delta$ be the median squared landmark distance excluding values at most $10^{-14}$ (one if none remain), and $\sigma^2=\max(\delta b^2,10^{-12})$ for $b\in\{0.25,0.5,1,2,4\}$. Symmetrize the Gaussian landmark Gram matrix and retain eigenvalues greater than $\max(10^{-12},10^{-10}\lambda_{\max})$. The block is $\Lambda^{-1/2}V^\top k_L(u)$, centered and scaled using A. Equal landmark count does not imply equal retained rank or feature width. See C. K. I. Williams and M. Seeger (2001), [Using the Nyström method to speed up kernel machines](https://proceedings.neurips.cc/paper/2000/hash/19de10adbaa1b2ee13f77f679fa1483a-Abstract.html), *Advances in Neural Information Processing Systems*, 13, 682–688.

For decoder features $X_f$ and three-column targets $Y$, fit ridge with an unpenalized intercept, minimizing mean squared training error summed across horizons plus $\alpha\|W\|_F^2$. With centered matrices $X_c,Y_c$ and reduced SVD $X_c=U\Sigma V^\top$, the coefficient matrix is $V\operatorname{diag}(s_i/(s_i^2+512\alpha))U^\top Y_c$. The intercept uses the A means. The penalty grid is $10^{-6},10^{-5},\ldots,10^2$. Select one penalty and, for nonlinear decoders, one bandwidth across the three horizons using B SMSE. Exact ties use ascending cap, bandwidth and penalty order. There is no A+B refit, no C tuning and no forecast clipping. Primary selections are separate using the same B observations, not independent validation sets. The secondary rule fixes the cap selected by affine-local linear ridge, then selects each procedure's settings at that cap. Raw histories do not have a cap search. The menu has 26 procedures and 3,294 ridge fits per task; every fit covers all three horizons.

The recorded SVD recovery uses SciPy `gesvd` on the same centered matrices if NumPy SVD fails. The coefficient audit uses Cholesky and, when required, an augmented least-squares QR calculation with design $[X_c^\top,\sqrt{512\alpha}I]^\top$ and response $[Y_c^\top,0]^\top$, using SciPy `gelsy`. The full-rank augmented design, coefficient and forecast comparisons require componentwise relative tolerance $2\times10^{-7}$ and absolute tolerance $2\times10^{-9}$. Unresolved failures stop the stage; tasks and candidates are not discarded. The original implementation of these checks is unavailable.

## Loss and inference

D SMSE averages squared error across 1,664 windows for each horizon, divides by that horizon's A target variance (divisor 512, floor $10^{-12}$), then averages the three normalized errors equally. Training variances are part of the fitted procedure. For each law and decoder the five comparisons are KAHM-local and KAHM-normalizer versus KAHM-memberships, and KAHM-local versus affine-local, positive-kernel-local and raw input. All 40 comparisons form one two-sided Bonferroni family. With 64 paired candidate-minus-reference differences $d_r$, intervals are $\bar d\pm t_{63,1-0.05/80}s_d/8$. The critical value is 3.37962646388. A wholly negative interval favors the candidate, a wholly positive interval favors the reference, and an interval containing zero leaves direction unresolved. No practical-effect or equivalence margin is specified. The nominal simultaneous 95% coverage depends on the paired-Student approximation. The repetition count was selected as the first of 32, 48, 64 and 96 with $t_{n-1,1-0.05/80}/\sqrt n\le0.45$, not a guaranteed power calculation.

## Numerical records and reproducibility limits

The [saved-loss bundle](../reproduction/score_enrichment/) preserves the full recorded 40-comparison family, selected losses, diagnostic and summary records, and independent statistical checker. The execution records describe a development-informed locally fixed protocol, with A/B selection completed before C/D generation and C/D predictions recorded before scoring. File hashes establish content identity, not authenticated execution chronology. The original full implementation, exact task roster, episode arrays, fitted model states, forecast arrays and complete environment fingerprint are unavailable. The recorded 9.024 GiB archive volume cannot be independently verified. The archived environment records Python 3.13.5, NumPy 2.3.5, SciPy 1.17.0, scikit-learn 1.8.0, threadpoolctl 3.6.0 and pytest 9.0.2 with three fresh-process workers and one numerical thread per worker.

Statistical recomputation reconstructs 416 procedure summaries, 2,560 paired differences and 40 adjusted intervals from 26,624 saved loss rows. It does not reconstruct forecasts, the complete candidate grid, target variances or the original fitting audit. Auxiliary tables are preserved and identity-checked; their analyses are not re-executed. The 64-repetition experiment and the executable 32-repetition experiments are distinct. See [Results](RESULTS.md) and [Reproduction](../REPRODUCIBILITY.md) for their separate comparison scopes.
