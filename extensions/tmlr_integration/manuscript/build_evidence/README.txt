receipts identify the review workspace; rendered page images are not
part of this source package. Visual receipts describe completed review,
not an automated visual guarantee. No experiments were rerun.

pandas; the forecast verifier also uses pdftotext. The supplied generated
assets compile without that extension. See the root build instructions.
