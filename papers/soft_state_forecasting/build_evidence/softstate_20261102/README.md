# Geometry-induced soft-state revision

This edition centers the manuscript on geometry-induced soft-state
abstractions and the predictive observables attached to them. The reference
gates, within-state coordinates, and reconstruction departures keep their
existing mathematical definitions and numerical implementation. A new
subsection connects augmented raw feature spans to conditional exact
Koopman closure under a specified deterministic history evolution.

The title, abstract, introduction, related work, method framing, theory,
decoder notation, experiment introduction, discussion, and supplementary
scope are revised. The new dynamical proposition is a function-space
statement with a proof; no state-propagation experiment is added.

This revision runs no forecasting models and adds no evaluation observations.
Generated empirical assets, evidence records, protocols, and reporting
builders are preserved. The earlier build directories retain their historical
scope. The current build and preservation records accompany this README.
