\title{Local Position and Reconstruction Features for Forecasting:\\
A Matched Study of Kernel Affine Hull Machines}
\author{Anonymous authors}
\begin{document}
\maketitle
\begin{abstract}
Soft memberships describe how a time-series history relates to local reference regions, but a forecasting readout may also require position within those regions. We study a hierarchy of membership, local-position, and reconstruction features using direct affine ridge forecasts of the same future observations. A matched experiment compares Kernel Affine Hull Machine (KAHM) reconstruction with positive-kernel radial-basis-function (RBF) reconstruction while holding reference histories, locality weights, projected kernels, and readout architecture fixed. Across 32 independent simulation repetitions, local-position features reduce mean nonlinear loss by 69.20\% relative to memberships alone. Adding KAHM reconstruction features reduces this loss by a further 10.46\%. Both improvements exceed the specified 3\% margins in a four-comparison confidence family. However, KAHM improves on matched RBF by only 0.03\% and does not establish the corresponding superiority margin. Its linear-control loss is 1.11\% higher than that of the position representation, within the specified 5\% noninferiority margin. The reconstruction benefit varies across laws and horizons. Algebraic results identify reference geometries for which KAHM and RBF have equal augmented raw feature spans and an irregular geometry for which they differ. These span results do not determine regularized forecasting performance. The evidence supports local position and conditional reconstruction enrichment for the tested affine readouts, rather than a general KAHM-specific forecasting advantage or an autonomous state model.
\end{abstract}
