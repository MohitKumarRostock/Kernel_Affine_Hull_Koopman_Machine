\section{Learning and certifying KAHM forecasts}
\label{sec:method}

The procedure has three stages. KAHM reconstruction models map each history
to geometric features; a constrained decoder maps those features to future
observations; and independent calibration assesses the resulting forecasts.
Keeping these stages separate also allows alternative representations to use
the same decoder and evaluation procedure.

\subsection{A fixed raw-output forecasting task}

Let $y_t\in\mathbb R^{d_y}$ be the observation at integer time $t$, where
$d_y\geq1$ is the number of observed coordinates. For a history length
$m\geq1$, define the column vector
\[
 x_t=(y_{t-m+1}^\top,\ldots,y_t^\top)^\top\in\mathbb R^{md_y}.
\]
Covariates available at time $t$ may be appended to this vector. A forecast
origin is a time $t$ at which a prediction is made using only this available
information. Let $\mathcal H$ be a finite, nonempty set of positive integer
horizons, ordered increasingly, and let $H=|\mathcal H|$ be its size. The joint
target is
\[
 Y_t=(y_{t+h}^\top:h\in\mathcal H)^\top\in\mathbb R^q,
 \qquad q=d_yH.
\]
Thus each training row contains all requested future observations in the same
order. The theory also considers one horizon at a time, in which case its
target dimension is $d_y$ (or one for a separately scored coordinate).

The history length, any fixed target transformation, horizons, and origin
sampling rule define the prediction task. Here ``raw output'' means the
observed signal under that fixed transformation, rather than learned feature
coordinates. When comparing history lengths, we use the same origins, starting
after the longest history is available. Every candidate is therefore evaluated
under the same target and origin law.

The main learner directly predicts each requested horizon, sharing a geometric
representation and a joint coefficient budget. It does not generate an entire
trajectory by iterating one-step forecasts. The rollout baselines instead
iterate a fitted feature-transition model and decode the resulting features.
Both approaches are evaluated on the same observed targets; a small one-step
feature error alone is not assumed to guarantee an accurate long rollout.

An \emph{episode} is one complete trajectory or other prespecified independent
sampling unit. Development data comprise training data, used to fit features
and coefficients, and validation data, used to choose hyperparameters or a
representative within each model family. Calibration data provide the
confidence bounds and may select among candidates frozen before calibration.
A separate test set describes forecasting performance after these decisions.
Its empirical error estimates population risk; it is not an exact risk value.

\subsection{KAHM dictionaries and stable soft associations}

A dictionary block describes a history through its associations with a set of
reference groups. KAHM associations depend on local reconstruction models.
Radial basis function (RBF) associations instead depend on distances to group
centers; affine-hull associations use residuals from fitted local affine
subspaces together with a locality term. Each construction specifies which
histories receive similar coordinates. A soft association retains a weight for
every group, while a hard assignment retains only the selected group. These
geometric choices need not preserve all information relevant to forecasting.

For block $b$, partition the training histories into $C_b\geq1$ reference
groups, indexed by $c=1,\ldots,C_b$, and fit their KAHM reconstruction models
as in \citet{kumar2024kahm,kumar2025collaborative,kumar2026limits}.
Let $\mathcal X$ be the history domain. The resulting score
$T_{bc}:\mathcal X\to[0,1]$ measures reconstruction discrepancy, with smaller
values indicating a closer match. It is a geometric score, not a class
probability.

The folding score combines reconstruction error and angular discrepancy
\citep[Section~3.3]{kumar2026limits}. Let $z(x)\in\mathbb R^{d_x}$ be the preprocessed history, where $d_x$
is its dimension, and let
$\widehat z_{bcj}(x)$, $j=1,\ldots,J_{bc}$, be the reconstructions supplied by
the $J_{bc}\geq1$ inherited local models for group $c$ in block $b$. Write
\[
 e_{bcj}(x)=1-\exp\{-\|z(x)-\widehat z_{bcj}(x)\|_2\},
 \qquad
 \theta_{bcj}(x)=\frac{\arccos\gamma_{bcj}(x)}{\pi},
\]
where $\gamma_{bcj}(x)$ is the cosine similarity
$\langle z(x),\widehat z_{bcj}(x)\rangle/
 (\|z(x)\|_2\|\widehat z_{bcj}(x)\|_2)$, clipped to $[-1,1]$;
when either vector has zero norm, the implementation sets this similarity
to zero. The inverse cosine $\arccos$ takes values in $[0,\pi]$. The group
score is
\[
 T_{bc}(x)=\min_{1\leq j\leq J_{bc}}
            \left\{\frac{e_{bcj}(x)^2+\theta_{bcj}(x)^2}{2}\right\}^{1/2}.
\]
Thus both discrepancy terms and the resulting score lie in $[0,1]$.
The inherited reconstruction training is unchanged; this formula specifies
how its outputs become the scores used by the forecasting representation.

Fix an exponent $\omega>0$ and offset $\tau>0$. The exponent controls the
contrast between affinities, and the offset keeps them positive. The reported
runs use $\tau=10^{-6}$. Define
\begin{equation}
 \Phi_{bc}(x)=
 \frac{(1-T_{bc}(x)+\tau)^\omega}
 {\sum_{r=1}^{C_b}(1-T_{br}(x)+\tau)^\omega},
 \qquad
 \Phi_b(x)=(\Phi_{b1}(x),\ldots,\Phi_{bC_b}(x))^\top.
 \label{eq:soft-features}
\end{equation}
Then $\Phi_b(x)$ lies in the probability simplex
\[
 \Delta_{C_b}=\{v\in\mathbb R^{C_b}:v_c\geq0\ \text{for all }c,
                                    \ \mathbf1_{C_b}^\top v=1\}.
\]
The coordinates express relative reconstruction affinity and need not be
calibrated probabilities. To evaluate \eqref{eq:soft-features} stably, set
$\ell_{bc}(x)=\omega\log(1-T_{bc}(x)+\tau)$ and
$\ell_b^{\max}(x)=\max_c\ell_{bc}(x)$, then compute
\[
 \Phi_{bc}(x)=
 \frac{\exp(\ell_{bc}(x)-\ell_b^{\max}(x))}
      {\sum_{r=1}^{C_b}\exp(\ell_{br}(x)-\ell_b^{\max}(x))}.
\]
Subtracting the maximum leaves the normalized weights unchanged. Replacing a
small denominator by uniform weights would change the representation, even
when relative weights remain numerically resolvable. A retained unit test
illustrates this issue: the direct powered affinities sum to less than
$10^{-12}$, yet one normalized association is essentially one.

The experiment manifest records source hashes for the inherited training and
folding routines. The forecasting contribution is the retained representation,
constrained output decoder, and calibration procedure. In the original
experiments, histories are standardized using training means and variances.
Section~\ref{sec:input-scaling} separately compares training-based range
scaling and bounded raw histories. The input subsample and the maximum number
of local training points are fixed by each configuration. Once fitted, the
feature maps remain fixed during decoder fitting and calibration.

At stage $s$, retain the first $s$ blocks:
\[
 \Gamma_s(x)=(\Phi_1(x)^\top,\ldots,\Phi_s(x)^\top)^\top
 \in\prod_{b=1}^s\Delta_{C_b}\subset\mathbb R^{p_s},
 \qquad p_s=\sum_{b=1}^s C_b.
\]
A \emph{prefix} means these first $s$ blocks. Their cluster partitions need
not be nested: preserving earlier forecasts requires retaining the earlier
coordinate functions, not their partitions. The experiments append blocks of
sizes $2,4,8,16$, giving prefix dimensions $2,6,14,30$.

\subsection{A constrained multihorizon decoder}

Let $N$ be the number of training histories. Form the response matrix
$\mathsf Y\in\mathbb R^{N\times q}$ with joint targets as rows, and the
feature matrix $F=[F_1,\ldots,F_s]\in\mathbb R^{N\times p_s}$, where
row $i$ of $F_b\in\mathbb R^{N\times C_b}$ is
$\Phi_b(x_i)^\top$. Fit an intercept $a\in\mathbb R^q$ and coefficient
matrix $W\in\mathbb R^{p_s\times q}$ by solving
\begin{equation}
 \min_{a,W}\ \frac1N\|\mathsf Y-\mathbf1_Na^\top-FW\|_{\rm F}^2
                   +\lambda\|W\|_{\rm F}^2
 \quad\text{subject to}\quad
                \sum_{b=1}^s\|W_b\|_{\rm F}\leq\kappa.
 \label{eq:training-objective}
\end{equation}
Here $W_b\in\mathbb R^{C_b\times q}$ contains the coefficient rows for
block $b$, $\lambda\geq0$ is the ridge parameter, and $\kappa\geq0$ is
the coefficient budget. The intercept is unpenalized. The loss sums squared
errors over all target coordinates and horizons, then divides by $N$; it is
not additionally divided by $q$ or $H$.

For a known output box $\mathcal Y\subset\mathbb R^q$ containing the
target, the reported prediction is
\[
 f_s(x)=\Pi_{\mathcal Y}\bigl(a+W^\top\Gamma_s(x)\bigr).
\]
The objective in \eqref{eq:training-objective} fits the unprojected affine
predictor; clipping is applied at prediction time and included in every
reported loss. Section~\ref{sec:theory} writes the same affine map as
$a+\sum_b W_b\Phi_b(x)$, using the transposed block convention
$W_b\in\mathbb R^{q\times C_b}$ to simplify its proofs.

Centering the training matrices eliminates the intercept. Projected accelerated
gradient then solves the constrained quadratic. Each projection computes the
block Frobenius norms, projects that nonnegative vector onto an $\ell_1$ ball
of radius $\kappa$, and rescales the blocks. The recorded first-order
optimality gap bounds the remaining training-objective error; a small change
between iterates alone would not give that bound. Appendix~\ref{app:optimization}
derives both the projection and the gap. The fitted-risk certificate remains
valid after early stopping, provided the returned model satisfies the budget
used for certification.

The ridge term regularizes fitting, whereas the block constraint defines the
feasible sensitivity class. Exact block duplication leaves that class unchanged,
but distributing coefficients across duplicates can reduce the squared
Frobenius ridge penalty. The replication results therefore concern feasible
prediction classes and their population obstruction. The separate numerical
test of duplicate-block optimum risks sets $\lambda=0$ and checks agreement
within the reported optimization gaps.

\subsection{Calibration and model selection}

The candidate family includes history lengths, dictionary prefixes, geometric
feature types, and baseline models. Each certificate compares a representation
lower bound with a fitted-model upper bound for the same observed target,
origin law, and decoder sensitivity budget. Algorithm~\ref{alg:procedure}
summarizes the procedure; Section~\ref{sec:theory} gives the score formulas
and their guarantees.

\begin{figure}[t]
\centering
\fbox{\begin{minipage}{0.94\linewidth}
\textbf{Algorithm 1: Learning and certifying KAHM forecasts}
\begin{enumerate}[leftmargin=*,itemsep=3pt]
\item Specify horizons, causal origins, known target bounds, RMSE tolerances
$\epsilon_h\geq0$, total failure probability $\delta\in(0,1)$, and a
candidate-cost rule.
\item Use development data to fit geometric blocks and constrained decoders
for their retained prefixes. Fit comparison models on the same observed targets.
\item Freeze all candidates, preprocessing choices, sensitivity budgets,
history-based strata, costs, concentration bounds, and proposed comparisons.
\item On $n\geq4$ independent calibration episodes, compute one mean squared loss per
episode and horizon. Compute obstruction scores using disjoint episode pairs
at matching origins. For stratified calibration, use one prespecified origin
per independent episode (or a justified episode-level stratum), pair within
strata, and estimate their masses and confidence intervals.
\item Allocate $\delta$ across risk bounds, mass intervals, alternative
partitions, and improvement comparisons.
Compute simultaneous lower endpoints $L_{jh}$ and upper endpoints $U_{jh}$
for candidate $j$ at horizon $h$.
\item Accept a fitted candidate when $U_{jh}\leq\epsilon_h^2$ for every
required horizon; exclude its representation class when
$L_{jh}>\epsilon_h^2$ for any horizon. Return the least costly accepted
candidate, if one exists, and the cost interval between the cheapest
nonexcluded class and the cheapest accepted fit.
\item Equal finite cost endpoints certify minimum feasible cost among the
declared classes. Exclusion of every class certifies infeasibility within that
family. Otherwise report the unresolved accuracy or cost decision explicitly.
\end{enumerate}
\end{minipage}}
\caption{Forecasting and certification for a finite family fixed before calibration.
The same procedure applies to alternative feature constructions. A candidate
fitted after inspecting calibration needs fresh evaluation data or a separately
justified adaptive guarantee.}
\label{alg:procedure}
\end{figure}

A lower endpoint above tolerance can motivate changing the representation or
budget, but does not establish that a particular change will help. Paired
episode losses therefore compare old and new fitted forecasts directly. They
can certify an improvement even when the representation obstruction is zero.
Conversely, the lower bound can exclude a restricted class even if no tested
refinement attains the desired accuracy.

In the experiments, cost is the number of retained feature coordinates, with
ties resolved by history length and then validation error. This measures
representation size. A deployment with unequal feature-evaluation costs can
use a different cost function, provided it is fixed before calibration.
