\section{Numerical representation and decoder specification}\label{sup:method}
\subsection{Reference construction and native local rank}
Input coordinates are standardized using all retained A histories. Each population standard deviation at most $10^{-12}$ is replaced by one. Two separate $k$-means partitions request 2 and 4 groups, using five initializations and at most 150 iterations. Too few distinct rows reduce the requested count. An unresolved empty-group result is retried with halved group counts, with all attempts recorded. Each group supplies at most 24 histories, sampled without replacement. Reference identities are fixed before the cap sweep.

Let $Q_j\in\R^{n_j\times d}$ contain local reference rows, with $d=12$, mean $\mu_j$, and cap $c\in\{1,2,4,8,12\}$. References are converted to float32 before native PCA and stored as such; subsequent calculations use float64. The initial rank request is $\min(c,d,n_j-1)$. Centered sample covariance uses divisor $n_j-1$, descending eigenvalue order, and the positive-eigenvalue threshold given by float64 machine epsilon. If the smallest projected reference-coordinate range is below $10^{-3}$, the requested rank is decremented and PCA is recomputed. This loop stops when the range condition holds or requested rank one is reached; a rank-one range violation is recorded, not hidden. The stored matrix $P_j$ and its actual column count determine the effective rank.

There is no additional ambient-minus-one restriction. Singleton or constant reference sets use an explicitly labeled rank-zero wrapper: all reconstruction rules return $\mu_j$ and there is no local-coordinate block. This is not a successful positive-rank native fit. Unexpected factorization errors stop execution. Full-rank affine projection returns the input exactly in the implementation, avoiding numerical angular artifacts around its mathematical identity.

\subsection{Reconstruction, reference regularization, and scoring}
For positive rank $r_j$, define $S_j$ as the sample covariance of $P_j^\top q_{ji}$ and use the kernel
\[
 \kappa_j(z,z')=\exp\left\{-\frac{[P_j^\top(z-z')]^\top S_j^{-1}[P_j^\top(z-z')]}{2r_j}\right\}.
\]
Let $G_j$ contain reference kernel values and $k_j(z)$ query/reference values. For one model suppress $j$, set $n=n_j$, and define reference energy $\nu=\|Q\|_F^2/(nd)$. Initialize $\lambda^{(0)}=2.5\nu$. At iteration $a$, compute
\[
 C^{(a)}=(G+\lambda^{(a)}I_n)^{-1},\qquad
 \lambda^{(a+1)}=2\nu+\frac{\|Q-GC^{(a)}Q\|_F^2}{nd}.
\]
Stop when the absolute change is at most $10^{-3}$ or after 100 inverse computations. Use the last computed inverse and its corresponding regularizer, not the uncomputed subsequent proposal. A nonpositive or nonfinite positive-rank regularizer is an error. This fits reference reconstruction without forecast targets.

The three maps are $Q^\top Ck/(\mathbf1^\top Ck)$ for KAHM, $Q^\top k/(\mathbf1^\top k)$ for positive-kernel reconstruction, and $\mu+PP^\top(z-\mu)$ for affine projection. Query squared distances use explicit differences after the projected metric transform, rather than subtraction of large expanded squared norms. Subtracting the largest log-kernel entry before exponentiation rescales a row by a common positive factor and leaves its exact normalized quotient unchanged.

For signed weights $a=Ck$, the relative denominator is $|\mathbf1^\top a|/\|a\|_1$ when the denominator is positive. The threshold is $10^{-10}$; a negative sum alone is not a failure. A failed finite-value or denominator check uses affine reconstruction and then recomputes the complete radial-and-angular score. No invalid query is assigned score zero merely because it used fallback.

For reconstruction $\widehat z$, let $e=1-\exp(-\|z-\widehat z\|_2)$ and $\theta$ be the clipped cosine angle divided by $\pi$. A zero norm sets the cosine to zero. The score is $T=\sqrt{(e^2+\theta^2)/2}$. With $\tau=10^{-6}$ and $\omega=16$, each partition forms log affinities $a_j=\omega\log(1-T_j+\tau)$, log normalizer $\zeta=\log\sum_j\exp(a_j)$, and memberships $\phi_j=\exp(a_j-\zeta)$. Log-sum-exp evaluates $\zeta$. There is no small-sum override to uniform memberships. Score clipping to $[0,1]$ protects against rounding; the inverse relation recovers the clipped scores. The origin convention gives the common score $1/(2\sqrt2)$ for exact zero reconstruction.

\subsection{Feature transformation and the nonlinear decoder}
The four input maps are $\phi$, $(\phi,\zeta)$, $\col(\phi,\{\phi_jP_j^\top(z-\mu_j)\}_j)$, and $T$. Each map uses its own reconstruction scores. All column means and population standard deviations are fitted on A. Standard deviations below $10^{-8}$ are replaced by one. The membership scaling is shared exactly across its enriched maps at the same cap, and an appended block receives its own column scaling. There is no deletion, radial transformation, or hidden raw-input augmentation.

Let $u\in\R^p$ be a standardized encoding. Linear ridge uses $u$ directly. The nonlinear decoder selects 64 A rows as landmarks with identical row identities across all representations and caps. Let $\delta$ be the median squared distance between distinct landmark positions, retaining distances greater than $10^{-14}$. If there are no such distances, set $\delta=1$. For multiplier $b\in\{0.25,0.5,1,2,4\}$, set $\sigma^2=\max(\delta b^2,10^{-12})$.

Define the 64-by-64 Gaussian landmark Gram matrix $K_{LL}$ and symmetrize it before eigendecomposition. Retain eigenvalues $\lambda_i>\max(10^{-12},10^{-10}\lambda_{\max})$, with corresponding eigenvectors in $V$. For the column vector $k_L(u)$ of landmark similarities and the diagonal retained-eigenvalue matrix $\Lambda$, the raw Nystr\"om vector is $\Lambda^{-1/2}V^\top k_L(u)$. Standardize only this new block with its A moments, and append it to the unchanged linear vector $u$. The result is a finite Nystr\"om decoder with a linear component \citep{Williams2001Nystrom}. Its width and retained kernel rank may vary between representations despite the same landmark budget.

\subsection{Ridge fitting and B selection}
For A feature matrix $X_f$ with $n_A$ rows and three-column target matrix $Y$, the objective is mean row-wise squared error plus $\alpha\|W\|_F^2$ with an unpenalized intercept. Let $X_c,Y_c$ be centered matrices, and let $X_c=U\Sigma V^\top$ be a singular value decomposition (SVD). Each ridge candidate uses
\[
 \widehat W=V\operatorname{diag}\left(\frac{s_i}{s_i^2+n_A\alpha}\right)U^\top Y_c,
\]
where $s_i$ are singular values. The intercept is the target mean minus the feature mean multiplied by $\widehat W$. Penalties are $10^{-6},10^{-5},\ldots,10^2$. The same penalty and nonlinear bandwidth are selected across the three horizons; the fitted coefficient columns are distinct. A summed-squared-error implementation uses penalty $n_A\alpha$.

For each candidate, B computes the mean of its horizon MSEs divided by the corresponding retained-A target variances, floored at $10^{-12}$. The first exact minimum in ascending cap, bandwidth, and penalty order is selected. Raw input has no duplicated cap search. The primary procedure independently selects the cap for each reconstruction/encoding/decoder combination. The secondary common cap is selected by affine-local linear ridge; each procedure retains its own best within-cap B settings. No C target affects a choice, and there is no A+B refit.

The menu contains 26 complete procedures, 366 candidate decoder bases, and 3,294 ridge heads per task. Counts of heads are search costs, not independent experimental units. The grid was expanded uniformly after development boundary selections, before the final data were generated. The 64-landmark budget is fixed, not selected; this study does not test a landmark-capacity interaction.

\subsection{Numerical recovery and failure accounting}
Only a NumPy SVD \texttt{LinAlgError} invokes the specified SciPy \texttt{gesvd} recovery. It uses the same centered matrices and objective and checks reconstruction, orthogonality, and normal-equation residuals. It does not change penalties, add jitter, remove columns, or delete a candidate. Other unresolved failures stop the stage. Predictions must be finite, and a complete-cohort audit is required for inferential release.

The independent coefficient audit first uses Cholesky normal equations. If factorization or agreement fails the declared tolerances, it solves the same problem by augmented QR using SciPy's \texttt{gelsy} driver:
\[
 \begin{bmatrix}X_c\\\sqrt{n_A\alpha}\,I\end{bmatrix}W
 \ \approx\ \begin{bmatrix}Y_c\\0\end{bmatrix}.
\]
The augmented design must have full column rank, and its coefficients and forecasts must agree under the unchanged tolerances. Every QR use is recorded. Coefficient and forecast comparisons use componentwise relative tolerance $2\times10^{-7}$ and absolute tolerance $2\times10^{-9}$. There is no complete-case analysis, substitute seed, reduced comparison family, or outcome-dependent grid extension.
