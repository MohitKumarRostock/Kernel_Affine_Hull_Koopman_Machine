# Policy-augmentation manuscript revision

This directory records the 1 November 2026 revision of the supplied author
source. The main paper adds Section 8; the Supplementary Studies adds the
policy study and its detailed protocol. The abstract, introduction,
discussion, study navigation, data citation and build instructions are updated.

The source/analysis files in `../../evidence/policy_augmentation/` are from
immutable published scientific and results records. Their existing full-run
audits are preserved, not rerun during manuscript revision. The current
numerical checks recompute the four paired primary endpoints and the natural
aggregates from published compact tables. No new forecasting model is fitted.

The evidence retains all unmet comparisons and adverse natural selections.
The corrected native rank policy, B-selected dimensions and preprocessing,
separate study families, and exact upper-bound decision convention remain
explicit. Existing theory and all earlier generated numerical assets are
preserved byte-for-byte.

`changes.patch` contains the editorial and reporting-code changes.
`preservation.json` compares the submitted source with this edition.
`build_and_text_verification.json` records compilation and displayed-number
checks. Visual receipts distinguish detailed page inspection from contact-sheet
overviews. `revision_summary.json` separates this reporting work from the
original experiments and from any later repository publication.
