
\section{Introduction}\label{sec:introduction}
A representation can be useful for forecasting because it makes predictive functions accessible to a restricted readout. This is different from increasing the information contained in the observed history. A deterministic transformation cannot supply observations that were absent from its input, but it can expose nonlinear functions that an affine predictor cannot otherwise express. This distinction is particularly important for local geometric representations, which can describe both membership in a reference region and position within that region.

We investigate which of these features improve direct prediction of an observed future value. Our starting representation contains nonnegative locality weights that sum to one within each reference partition. We then add gate-weighted principal coordinates and, finally, departures of a nonlinear reconstruction from its local affine projection. The nonlinear reconstruction is a Kernel Affine Hull Machine (KAHM) \citep{Kumar2024KAHM}. A matched positive-kernel radial-basis-function (RBF) reconstruction provides the principal control for deciding whether any benefit is specific to KAHM.

The experiment compares four inputs to the same class of affine ridge readouts: memberships alone (G), memberships with local position (P), P with KAHM departures (K), and P with matched RBF departures (R). Each readout predicts the same future observation. No procedure retains a separate raw-history predictor or fits a correction to such a predictor. The membership coordinates are identical across all four inputs, and the position coordinates are identical across P, K, and R. In the primary comparison, P selects the common reference bank using validation data. This deliberately conditions the reconstruction comparison on a geometry chosen without either reconstruction block.

The strongest empirical result is a hierarchy of predictive usefulness under this specified procedure. Local position substantially improves the membership-only readout. KAHM departures then improve the position readout, but they do not establish the specified advantage over matched RBF departures. The aggregate reconstruction benefit is not uniform: KAHM worsens the position readout on nonlinear autoregression and at the shortest horizon. We therefore interpret the result as evidence about feature design for restricted readouts, not as a recommendation to use KAHM for arbitrary forecasting tasks.

The mathematical analysis addresses a complementary question. Normalizing inverse-Gram kernel weights can change the reconstruction formula without changing the augmented span of raw features available to a linear readout. We give a sufficient condition for equality of the KAHM and RBF spans and an explicit class of irregular scalar reference geometries for which they differ. Both statements concern fixed geometry before nonlinear feature transformations and ridge fitting. They neither establish a forecasting advantage nor assert that either representation has closed autonomous dynamics.

\paragraph{Relation to existing methods.}
Forecasting from delay coordinates with local approximation has a long history \citep{Farmer1987Prediction}. Local coordinate coding and local tangent coding motivate localized features and weighted principal-coordinate displacements \citep{Yu2009LCC,Yu2010LTC}; local affine experts provide another closely related construction \citep{Jacobs1991Experts}. The position block is consequently a substantive control, rather than a new coding principle. KAHM supplies a particular nonlinear reconstruction of reference histories \citep{Kumar2024KAHM,Kumar2025Collaborative}. Its positive-kernel control is a vector-valued normalized kernel smoother \citep{Nadaraya1964Regression}. The quotient interpretation of KAHM is related to rescaled kernel interpolation \citep{Deparis2014Rescaled,DeMarchi2017Rescaled}.

The distinction between information preservation and accessibility to a restricted predictor also appears in supervised dimension reduction and predictive information theory \citep{Fukumizu2004SDR,Xu2020Usable}. Our evaluation concerns fitted affine readouts, not unrestricted Bayes risk. Likewise, it differs from methods that explicitly learn the evolution of a latent representation, such as VAMPnets and Koopman embeddings \citep{Mardt2018VAMPnets,Lusch2018Embeddings}. A separate KAHM study uses reconstruction-score-normalized memberships and successor-coordinate targets \citep{KumarKargaran2026Limits}. Those memberships and targets differ from the center-distance gates and observed-response targets used here. The present contribution is the matched feature comparison and its algebraic interpretation, rather than a new normalization rule or a validated state-transition model.
