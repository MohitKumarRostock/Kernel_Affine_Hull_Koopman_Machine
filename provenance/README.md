# Computational provenance

The protocol and input digests identify the experimental specifications and source records used for execution. The readable [protocol specification](../docs/PROTOCOLS.md) defines the numerical procedures; the compressed protocol records retain the original specifications. The synthetic study uses the spawned-worker implementation with the stated sampling design and comparison definitions. No result records were produced by unsuccessful process-start attempts. The observed-series study uses the included public-domain CO2 snapshot. Neither investigation is represented as externally preregistered.

The protocol and input hashes identify content and are not authenticated timestamps. Execution environments and replay receipts are stored with the respective numerical records. Replay receipts concern numerical outputs, not equality of elapsed runtimes.
